# 我的英语课 — Mac 桌面版 (v1.0)

这是网站的 Mac 桌面应用外壳：界面内容和网站完全一样（同一份 `index.html`/`css`/`js`/`data`），唯一的区别是 AI 对话的网络请求改成从 Electron 的主进程（Node.js）发出，而不是网页里发出。这不是浏览器环境，完全不受浏览器的 CORS 限制——所以像 Kimi 这种不允许网页直接调用的服务商，在桌面版里也能正常使用。

界面做了一套"玻璃质感"的专属皮肤（毛玻璃、动态渐变背景、科技感高光），只在桌面版生效，网站本身外观不变。

## 我没办法帮你做的事

这个开发环境是云端的 Linux 容器，没有 macOS，也没办法运行/编译真正的 Mac App。下面的构建步骤需要你在自己的 Mac 上执行。代码我已经尽量写对并做了语法检查，但从没真正启动运行过——如果第一次跑遇到报错，把报错内容发给我，我可以继续帮你排查。

## 需要准备

- 一台 Mac
- [Node.js](https://nodejs.org)（装 LTS 版本就行，装好后终端里能跑 `node -v` `npm -v` 即可）

不需要 Xcode，不需要开发者账号——打包出来的是未签名的 app，第一次打开时 macOS 会提示"无法验证开发者"，右键点 app → 打开，再确认一次就行，之后就正常了。

## 构建步骤

打开"终端"（Terminal），依次执行：

```bash
# 1. 进入这个文件夹（把路径换成你电脑上实际的仓库路径）
cd English/electron

# 2. 安装依赖（只需要做一次）
npm install

# 3. 打包成 Mac App
npm run dist
```

打包完成后，`dist/` 文件夹里会有一个 `.dmg` 安装包，双击打开，把"我的英语课"拖进 Applications 文件夹即可。

## 先本地试运行（不打包，改代码后快速看效果）

```bash
cd English/electron
npm install   # 如果还没装过
npm start
```

这样会直接打开一个窗口跑起来，不用等打包，适合先确认能不能正常显示、AI 对话能不能用。

## 用法

打开 App 后，操作和网站完全一样：⚙️ 设置里填 AI 服务商的 API Key（Anthropic、Kimi，或任何 OpenAI 兼容接口都可以，包括之前网页版被 CORS 挡住的 Kimi Code Plan）。因为这里是桌面 App，不需要再搭 Cloudflare Worker 代理——`接口地址 Base URL` 直接填服务商真实的地址即可（例如 Kimi 就填 `https://api.kimi.com/coding/v1`），`API Key` 填你自己的真实密钥。

## 进度数据不会自动同步

桌面版 App 和网站是两个独立的"存储空间"，各自的学习记录（单词掌握情况、连续天数等）不会自动同步。如果想把某一边的记录搬到另一边，用"学习进度"页面的"导出学习记录 / 导入学习记录"按钮手动倒一次就行。

## 以后要发新版本

改了网站代码后，想让桌面版也更新，重新跑一遍 `npm run dist` 打包一个新 `.dmg` 替换旧的即可，`electron/main.js` 会自动使用最新的网站代码（`prepare-site` 脚本每次打包前都会重新从上一级目录拷贝一份最新文件）。
